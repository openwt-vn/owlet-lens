# Code of conduct

We want this project to be a respectful place to ask questions, report problems and contribute.

## What we expect

- Be kind and patient. Assume good intent.
- Disagree with the idea, not the person. Keep feedback specific and useful.
- No harassment, insults, discrimination, or personal attacks, in any language.
- Do not publish other people's private information.
- Keep the discussion on topic: the project, its code and its use.

## What happens

Maintainers may edit or remove comments, close issues and pull requests, and block people who do not follow this code, to keep the project a safe place for everyone.

## Reporting

If you see or experience behaviour that breaks this code, tell a maintainer privately through their GitHub profile. Do not post it in a public issue. We will read it and answer.

This applies in the repository, its issues, pull requests and Discussions, and when someone represents the project in public.
