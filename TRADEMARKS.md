# Name and logo

"Owlet Lens" and the Owlet Lens logo identify this project. The Apache License 2.0 that covers the source code does not grant the right to use them (section 6 of the license). This page says what you can do.

## You can, without asking
- Write "Owlet Lens" in text to refer to this project: articles, talks, documentation, issues.
- Say that your tool works with Owlet Lens, uses it, or is a fork of it, as long as it is clear that your tool is not the official project.
- Use the logo, unchanged, to link to this project.

## You need permission to
- Name a product, company, domain, package or social account "Owlet Lens", or something that can be confused with it.
- Use the logo in a way that suggests OpenWT sponsors, endorses or is part of your product.
- Change the logo or its colours.
